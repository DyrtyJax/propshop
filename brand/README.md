# PropShop brand

PropShop should feel like a real backstage workshop: inventive, practical, slightly theatrical, and full of labeled drawers. It should not look like a generic AI dashboard.

## Voice

- **Positioning:** The creative build system for coding agents.
- **Invitation:** Need a thing? Send it to PropShop.
- **Vocabulary:** props, takes, shop floor, call sheet, promote, shelves, open for business.
- **Tone:** confident and playful; never cute at the expense of clarity.

## Palette

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#201827` | Type, outlines, terminal surfaces |
| Warm paper | `#FFF0C7` | Primary ground |
| Prop red | `#FF5A47` | Brand action and emphasis |
| Workshop mint | `#63D7C5` | Secondary accent |
| Marquee amber | `#FFB74D` | Secondary accent |

Use hard outlines, inventory labels, stamps, tickets, contact sheets, and visible run identifiers. Avoid glassmorphism, purple-blue gradients, magic wands, and humanoid robot imagery.
